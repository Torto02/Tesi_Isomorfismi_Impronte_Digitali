# Fingerprint Graph Matching Project

Questo progetto implementa un sistema per il confronto di grafi basati su impronte digitali. Utilizza algoritmi di estrazione di sottografi, matching e visualizzazione per analizzare e confrontare strutture grafiche.

## Requisiti

Assicurati di avere Python 3.8 o superiore installato sul tuo sistema. Per installare le dipendenze necessarie, esegui il seguente comando:

```bash
pip install -r requirements.txt
